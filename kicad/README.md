# KiCad (Falkor Electrical)

Deze map bevat het KiCad-project voor het elektrische systeem van Falkor (schematic-only).

## Startpunt

- Open `falkor-electrical.kicad_pro`

## KiCad-versie

Dit project wordt onderhouden met **KiCad 10**.

## Inhoud

- `schematics/` — hiërarchische schema’s (00/10/20/24/40/50/60)
- `sym-lib/` — project-specifieke symbolen
- `project-lib/` — toelichting en scope van project library (zie `project-lib/README.md`)
